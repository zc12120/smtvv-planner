# 三种游戏外观与资料阅读

界面服务于游戏中途查资料、配置八个技能和核对合体步骤的玩家。当前方向为青金圆角图鉴：深海青章节栏与石白阅读面形成层次，旧金细线、召唤环和角色原色保留游戏气质。表面采用柔和圆角、轻投影与细边框，半透明导航和分段控件借鉴苹果界面的清晰层次；正文使用正常字宽。以紧凑面板、并排角色资料和连续步骤提高信息密度，完整说明仍可阅读。

新访客默认使用 SMT V 浅色。手动选择保存在 `smtvv-appearance`，在刷新、详情页和语言切换后继续生效。登录页与管理后台固定为 SMT V，深浅和字号共用前台偏好；不会改动合体配置。


| 外观 | 色彩与结构 | 展示字体 |
| --- | --- | --- |
| SMT V | 石白、玉青、墨蓝与旧金；细线召唤环、安静的资料层级 | Cinzel + Noto Serif CJK |
| P5 | 纸白、墨黑、绯红；圆角红色选中状态、细线头像底形、黑底标题 | Archivo Black + 粗体 Noto Sans CJK |
| P3 Reload | 钴蓝、冰青、午夜蓝；蓝色标题平面、轨道线与几何编号 | Chakra Petch + Noto Sans CJK |

每套外观包含独立的浅色和深色变量。弱点、耐性、无效、反弹和吸收同时使用文字与颜色，不依赖颜色辨认。
弱点为红色、耐性为蓝色、无效为绿色、反弹／吸收为金色；卡片、目标和详情共用状态色。
浅色弱点与耐性使用低饱和底色和深色文字，辅助文字与输入边框保持清晰；普通文字以实际底色下至少 4.5:1 的对比度为目标。

## 阅读与交互

- 正文使用本地 Barlow 与对应语言的 Noto Sans，桌面 17px、手机 16px；大字号分别为 20px、18px。展示字体只用于标题，数值与操作使用正常字宽。
- 效果说明为 `.9375rem`（约 15–16px），辅助信息为 `.8125rem`（约 13–14px），耐性、来源与计数等小标签为 `.75rem`（12–13px）。所有层级随大字号设置缩放，手机保持同一套字号变量。
- 基础间距为 4px，组件一般使用 12–16px 内边距，主要区域间距为 16–20px。数据行距为 1.5–1.7，长篇介绍为 1.8。中等屏幕减少技能列数，最窄屏幕和手机大字号使用单列技能卡。
- 三主题共用圆角变量：小标签 10px、控件 14px、内嵌卡 16px、资料卡 22px、面板 26px、弹窗 30px。手机面板为 22px、弹窗为 26px；卡片底栏和面板标题匹配外层弧度，菜单、提示与焦点轮廓保持可见。加载占位沿用对应容器的圆角，技能卡移除旧折角，容量刻度使用竖向圆头。
- 页头保留 Logo、放大镜搜索入口与显示设置。手机设置收在菜单中，隐藏重复的页面标题横栏，为配置和资料内容留出空间；导航保留 44px 触屏操作区域。全局搜索以独立宽面板显示，不受页头按钮宽度限制。
- 桌面配置将目标摘要和技能网格并排；手机将目标摘要、技能和条件顺排，目标耐性、习得技能与高级条件按需展开。技能卡提供替换、移除和来源入口，手机生成路线按钮固定在可操作位置，并在软键盘展开时让出空间。
- 桌面仲魔卡展示头像、种族、等级、合体类型与七属性耐性；手机保留身份信息和操作入口，完整属性在预览与详情中阅读。技能卡优先显示效果与消耗；灵体卡优先显示匹配技能，手机默认展示前两项。卡片主体进入详情，配置、预览与卡内技能链接保持独立。
- 资料卡按内容区宽度自动排列，手机使用紧凑单列；图片保持原比例。生成、替换、移除、筛选和预览等触屏操作区域至少 44px。
- 技能列表按分类菜单的属性顺序分组排列，同属性保持稳定次序；搜索、继承筛选、重置和语言切换保持同一规则。
- 三个资料列表分别提供「每行」选择，支持自动或最多 1–6 项，偏好独立保存在 `smtvv-catalog-columns-v1` 并在标签页间同步。自动模式沿用原有卡宽；手动模式最小卡宽为仲魔 208px、技能／灵体 240px，窄屏自动减少实际列数。调整密度保留筛选、配置和焦点，重置筛选保留密度。手机使用带可访问名称的重置图标。
- 仲魔卡的七属性在不足 18rem 的容器中排为四列两行，较宽时七列一行。完整状态词保持一行，采用 600 字重与状态色细边框；普通属性透明底，突出耐性和无效等特殊状态。
- 自动模式的大字号技能卡使用 18rem 最小宽度和 16px 内边距、间距，让列数随阅读字号调整。分类置于首行，名称、原名和效果左对齐；名称为 1.1rem，效果沿用大字号。消耗与继承分为两栏，标签位于数值上方，来源和预览在卡片底部对齐；手动密度下卡宽不超过 17rem 时，来源与预览分行。分类按钮直接显示当前选项。
- 三个资料页采用同排的放大镜、分类选择与二级筛选。去掉可见的左侧说明与 INDEX 编号，两个选择器共用下拉按钮和选项面板；选择后收起，支持方向键、Home / End、Escape、外部点击关闭与焦点返回。搜索展开为整行输入框，收起后显示有效搜索条件；筛选、重置与详情返回保留一致状态。
- 预览使用原生模态 `dialog`，桌面为 440px 侧栏，距窗口边缘 16px；手机距边缘 8px，保留四角弧度。内边距桌面 24px、手机 20px，背景轻微虚化。支持关闭按钮、Escape 和点击背景，关闭后焦点返回原按钮；列表宽度和原滚动位置保持稳定。仲魔预览列出七属性耐性、固有技能与配置入口，肖像区域高 132px。减少动画模式同时关闭卡片与抽屉动画。
- 仲魔详情页在 1200px 及以上将完整介绍放在头像与基础资料右侧，1199px 及以下顺排在基础资料下方；能力、耐性和技能接续在页头之后。仲魔头像在桌面使用 224×184px、手机使用 112×112px，389px 以下宽度收至 96px，为长名称留出空间，图片始终保持原比例；名称、基础资料和配置入口合并为紧凑页头，手机资料使用两列。介绍保留完整自然段、1.8 行高与最多 68ch 的阅读宽度；技能详情说明也限制为 68ch。699px 以下的技能表改为名称和操作在上、完整效果在下的条目，保留表格语义和所有数据。
- 桌面路线方案使用分段选择栏，同时展示费用和操作数；手机使用紧凑方案选择器与当前方案摘要。其他计算目标按需计算，完整解释可在方案对比中查看。
- 桌面路线步骤以加号和箭头连接材料与结果，技能显示在对应仲魔或灵体下方；手机先展示材料、结果与技能变化摘要，完整来源在每步明细中展开。
- 路线头像桌面为 112px、窄屏 88px；名称分别为 1.5rem、1.375rem，技能名称为 1rem。三份及以上材料分组，窄屏纵排；结果列显示完整保留技能。
- 来源显示「起始材料」「第 n 步产物」，保留跳转与完整导出。移除完成勾选和进度；手机步骤目录横向滚动，编号跳转、刷新与详情返回时恢复当前步骤。
- 技能搜索仅匹配名称和名称译名，属性分类通过分类按钮筛选。前台页底不再显示站点标语或数据来源折叠说明。
- 卡片呈现使用 180ms 淡入上移 4px，最多八档 16ms 错开；头像悬停上移 2px、图鉴头像放大至 1.015 倍，预览进入为 240ms。`prefers-reduced-motion: reduce` 停用这些动画。
- 图片缺失时使用文字身份占位。八槽配置、计算、来源指定、长路线、导出和进度恢复继续沿用原功能。

## 样式入口

`web/auth/theme/typography.css` 提供本地字体、语言回退与标题家族。
`web/experience.css` 加载于旧结构样式之后，统一三套外观、资料卡、筛选菜单、预览与详情。
`web/components.css` 集中管理共用配置控件、搜索面板及手机布局；`web/task-controller.js` 管理请求标识、计算阶段、取消与轮询。
`web/catalog-ui.js` 负责三个资料列表的呈现、分类按钮状态与独立列数偏好；筛选与配置保存逻辑保留在 `web/app.js`。
列表按原始名称复用节点，灵体搜索只更新匹配的技能清单，保留卡片与头像。页面仅挂载当前资料列表，离开时释放节点缓存；筛选、列数与滚动位置独立保存。卡片使用真实自然高度，不估算长列表高度，以确保返回时仍停在原条目。

`web/site.js` 缓存图标与标准化搜索文本，NFKC 处理全角输入；输入法组合期间不提交选择。四个页面预加载必要脚本，在首次绘制前恢复保存的字号；字号、主题与外观支持跨标签同步。配置与路线页签提供 `aria-controls`、方向键和 Home / End 操作。
路线头像使用独立的 `route` 尺寸，按桌面 112px 显示宽度选择 DPR 对应的 WebP，图片失败继续回退至裁剪 PNG、原图和文字占位。

`web/inspector.js` 提供完整预览。配置页、资料卡和详情共用 `GameSite.skillUI.resists`，为每种属性和耐性提供可访问名称。

登录页与后台共享 SMT V 的青金调色板、Barlow 正文、Cinzel 与 Noto Serif 标题。登录页为 480px 居中表单，手机直接呈现表单；深浅与字号复用前台偏好。登录页样式与外观启动逻辑位于 `web/auth/theme/login.css` 和 `smtvv.js`，后台样式保留在 `web/admin/admin.css`。

## 游戏参考

三主题设计沿用此前按用户要求检索的官方参考：

- [SMT V: Vengeance 官方网站](https://megaten5.jp/vengeance/)：角色构图、青金配色、仪式感标题和细线装饰。
- [Persona 5 Royal 官方网站](https://p5r.jp/)：红黑白对比、粗标题与切角平面。
- [Persona 3 Reload 官方网站](https://p3re.jp/)：钴蓝空间、冰青高光和几何排字。
- [Fontworks 的 Persona 5 字体案例](https://fontworks.co.jp/case/3471)：厂商列出 Slump 在 P5 游戏文字中的使用。本项目选择开放许可字体表达相近的视觉性格，不声称它们是游戏原版商业字体。

阅读检查参考 [WCAG 2.2 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字至少 4.5:1，大字至少 3:1。
[视觉呈现说明](https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation) 中的行宽建议用于改善长篇阅读；它属于 AAA 指导，不作为本项目已通过完整 WCAG 认证的声明。`ch` 随字体变化，68ch 也不表示精确的中文字数。

## 字体来源与构建

新增字体放在 `web/auth/theme/fonts/`，全部本地提供，使用 `font-display: swap`。
授权和上游链接见 [第三方通知](../THIRD_PARTY.md) 与 [资源来源](../web/assets/SOURCES.md)。

`scripts/build_interface_fonts.py` 不访问网络，读取事先准备的上游 TTF 和 OFL 文件，生成 WOFF2 子集：

```sh
python3 -m venv /tmp/smtvv-font-tools
/tmp/smtvv-font-tools/bin/pip install fonttools brotli
/tmp/smtvv-font-tools/bin/python scripts/build_interface_fonts.py /字体源目录 \
  --cjk-source /usr/share/fonts/opentype/noto
```

字体源目录包含 `Barlow-{Regular,Medium,SemiBold,Bold}.ttf`、`Cinzel.ttf`、
`ArchivoBlack-Regular.ttf`、`ChakraPetch-SemiBold.ttf`，以及 `Barlow-OFL.txt`、
`Cinzel-OFL.txt`、`ArchivoBlack-OFL.txt`、`ChakraPetch-OFL.txt`。
CJK 源目录提供 `NotoSerifCJK-Bold.ttc`，面向五种语言的标题字符由界面词典、
资料名称和可选本地游戏语言包收集。发布现有完整语言包时，应一并构建相应子集。
正文 CJK 子集继续由 `scripts/build_locale_fonts.py` 维护。

## 验证

在隔离本地服务及完整本地游戏资源可用时，运行：

```sh
npm run test:visual
npm run test:i18n
npm run test:browser
npm run test:collections
npm run test:refinement
```

集合测试覆盖搜索与组合筛选、重置、详情返回、完整预览、键盘焦点、手机分类折叠、
五语 × 三主题 × 深浅模式、大字号、减少动画和缺图回退。原测试继续验证八技能配置、
59 步路线、进度与导出。在会重置本地静态 HTTP 连接的 WSL 环境，可设置
`SMTVV_STATIC_FROM_DISK=1` 使用已有静态文件夹具；计算与资料 API 仍访问真实服务。
发布检查应直接使用正常 DNS 下的公网 HTTP 与浏览器。
