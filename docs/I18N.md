# 多语言界面与本地游戏文本

前台和登录页支持 `zh-Hans`、`en`、`ja`、`zh-Hant`、`ko`。默认简体中文，
使用顶部菜单切换，或在页面 URL 中指定 `?lang=ja`。选择保存在
`smtvv-language`，不会改写账户、外观、合体配置或进度的存储键。
切换会重新加载页面，从已有缓存恢复路线，不重新创建计算。

`web/auth/theme/i18n.js` 负责显示层翻译，
`web/auth/theme/locales/*.json` 是可直接维护的界面词典。花括号数字是插值，
翻译必须保留同一组占位符。动态页面按文本节点及明确列出的可访问性属性翻译，
不替换 HTML、不修改输入框的值、URL 标识、数据属性或用户发布的公告。
仲魔与技能的英文内部 ID、计算请求及保存的路线对象始终使用原值。

目录与技能详情在显示前合并当前语言的游戏文本。搜索支持当前语言、英文标识及
语言包内的其他语言名称。规则、费用和继承结果不因语言不同而改变。
管理后台继续使用原有语言。

## 官方语言资源

四种新增语言的游戏正文来自用户自行提供的本地游戏资源，放在
`web/assets/locales/en.json`、`ja.json`、`zh-Hant.json`、`ko.json`。
这些文件随完整发行版及默认 Docker 镜像提供，也可以通过
`compose.assets.yaml` 的只读 `web/` 挂载使用。
翻译词典和开放许可字体属于公开应用文件，可从 `/auth/theme/` 加载；
游戏语言包与其他游戏资料遵循业务站点原有访问控制。

语言包目前覆盖每种语言的 275 位仲魔、537 项普通及固有技能、296 个灵体，
并使用游戏的任务名称表翻译解锁条件。介绍保留原文自然段，去掉固定屏宽造成的
换行；英语和韩语保留单词间空格。技能描述中的属性、目标、攻击次数和异常状态
标签根据固定版本数值展开，未知标签会使构建失败。

维护工具 `scripts/build_game_locales.py` 接收已经从本地游戏导出的消息表目录：

```sh
python3 scripts/build_game_locales.py /私有目录/游戏消息表
```

目录须包含五个 `raw-<language>.json`，每个包含 `source`（language、
steamBuildId、pakIndexSha1）及 `tables`。所用表为 `demons`、`profiles`、
`races`、`skills`、`effects`、`items`、`quests`；每行保留 `label` 和
字符串列表 `pages`。需先安装带 `gameId` 的 `data/demon-profiles.json` 身份映射。
工具按序列化标签中的 ID 匹配，不能用数组位置或 `MessageID` 代替技能 ID；
名称与效果表存在一行偏移。所有语言必须来自同一游戏构建和 PAK 索引。
工具只读取导出的数据，不修改游戏安装。

没有可选语言包时，界面语言仍可切换，游戏文字使用已有资料回退；
完整官方本地化需要安装对应语言包。网络下载失败不会改写配置或路线进度。

## 字体与检查

JP / TC / KR 使用本地 Noto Sans CJK 常规与粗体 WOFF2 子集，无第三方字体请求。
拉丁正文使用正常字宽的 Barlow；SMT V 标题按语言使用 Noto Serif CJK 子集，
P5 和 P3 Reload 的展示字体及构建方式见 [界面设计](DESIGN.md)。
许可在 `web/auth/theme/fonts/OFL.txt`。需要重新生成时，在安装 `fonttools`
和 `brotli` 的 Python 环境执行 `scripts/build_locale_fonts.py`，可用 `--source`
指定包含 `NotoSansCJK-Regular.ttc`、`NotoSansCJK-Bold.ttc` 的目录。

安装完整本地语言包并启动隔离的本地服务后：

```sh
python3 server.py --port 8766
# 另开终端
npm run test:i18n
npm run test:visual
npm run test:browser
npm run test:collections
```

多语检查覆盖真实计算、五语切换、原始路线对象与进度不变、跨语言搜索、
官方介绍及技能、语言资源失败恢复、键盘菜单，以及 320–1440px 的前台和登录页。
原有视觉与路线检查继续覆盖大字号、其他主题和 59 步长路线。
