# Persona 3 Reload artwork

The protagonist artwork was obtained from the [official ATLUS Persona 3 Reload website](https://p3re.jp/). The character profile on that page identifies both illustrations as the protagonist.

- [School uniform illustration](https://p3re.jp/resources/img/top/character_modal/img_character1_f234d553552dd807c323dfecb0663805.webp): used in the planner's P3 Reload banner.
- [Battle uniform illustration](https://p3re.jp/resources/img/top/character_modal/img_character1_battle_a100337e6e24dd2f2e97b63e3de283f3.webp): used on the authentication page.
- [Official logo](https://p3re.jp/resources/img/common/logo_color_a0ae396768813e9f6a6e710194abcc94.webp): retained alongside the protagonist illustrations.

Images are cropped only to remove transparent margins and saved as WebP. Source URLs, dimensions and file hashes are recorded in `manifest.json`. They are served from the same host, without hotlinking or third-party requests during login.

The login theme uses Barlow Condensed and a Noto Sans SC subset covering the authentication portal's Simplified and Traditional Chinese translations. Both fonts are under SIL OFL 1.1; their notices are included in `web/auth/theme/`.
